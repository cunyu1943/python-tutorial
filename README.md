# Python 学习指南

## 一、项目简介

### 1.1 项目概述

「Python 学习指南」是一个面向 Python 初学者与进阶学习者的开源文档站点，旨在通过系统化的知识梳理与丰富的代码实例，帮助读者从零开始掌握 Python 编程。站点基于 VitePress 构建，默认启用深色主题，并集成全文搜索、RSS 订阅、Git 变更日志、公告弹窗、打赏等功能，开箱即用。

### 1.2 内容结构

站点内容按照循序渐进的学习路径组织，共分为以下模块：

1. **学习指引**：整体学习路线与大纲导航，引导读者按顺序学习；
2. **基础教程**：涵盖 Python 简介、PyCharm 使用、语言元素、控制流程等核心基础知识；
3. **基础实例**：共 55 道编程实例，按每组 5 题分为 11 组，巩固基础语法与算法思维；
4. **实战训练**：通过 Turtle 图形库、数码管绘制、购物车等小项目进行综合实战；
5. **Bug 解决**：记录 Python 开发中常见问题的解决方案。

### 1.3 适合人群

- 零基础入门 Python 的初学者；
- 希望通过实例巩固语法与编程思维的学习者；
- 需要查阅常见 Bug 解决方案的 Python 开发者。
